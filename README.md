# slam-core

A geometry-first Visual-Inertial SLAM project focused on pose estimation, sensor fusion, factor-graph optimization, loop closure, visual debugging, benchmarking, and failure analysis.

## Goals

- Clean, readable geometry-first VIO implementation.
- Reproducible benchmarks on EuRoC MAV and TUM-VI.
- GTSAM/iSAM2 pose graph with loop closure.
- Rerun-based visual debugging and failure analysis.
- Documented failure modes and engineering decisions.
