# Dataset Setup

Dataset download and preparation instructions will be added as implementation progresses.

## Planned Datasets

- **EuRoC MAV** — ASL Robotics, stereo + IMU, indoor.
- **TUM-VI** — TUM, fisheye stereo + IMU, indoor/outdoor.
- **KITTI** (optional) — Karlsruhe, stereo + IMU, driving.

## Notes

- Datasets are git-ignored (`data/` is in `.gitignore`).
- Scripts for download, extraction, and calibration file placement will live in `scripts/` once created.
- Expected directory layout and calibration format will be documented here.
